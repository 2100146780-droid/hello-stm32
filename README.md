# hello-stm32

我的第一个 Git 练习仓库，用来走通「本地编写 → add → commit → push → GitHub」的完整流程

之后会在这个仓库里放 STM32 入门代码：点灯、按键消抖、串口打印。

## 环境记录

| 项目 | 值 |
|---|---|
| MCU 目标板 | STM32F103C8T6（计划） |
| IDE | STM32CubeIDE |
| Git | 2.55.0 (Windows) |
| 连接方式 | SSH over 443 端口 |

## 目录结构

```
hello-stm32/
├── README.md          本说明文件
├── .gitignore         忽略编译产物
├── notes/             学习笔记
└── src/               源代码（以后放）
```
